## 1. 已拍板口径

### 1.1 配置形态

| 项 | 口径 |
|----|------|
| 是否单独配置页 | **是**。PC「配置管理」下单独菜单「预约时段」 |
| 两套数据 | `bizType = CLEANING` / `RECYCLING`，互不共用 |
| 页内交互（本主题） | 两个 Tab（保洁时段 / 废品回收时段），对标关键词配置页 |
| 同一页后续（下一主题） | 页**顶部**再加「保洁缓冲分钟 / 废品缓冲分钟」；本主题不要做 |
| 单条字段 | 时段文案（如 `08:00`）、排序、启用 / 停用 |
| 唯一性 | 同一 `bizType` 下时段文案唯一 |
| 历史订单 | 只存字符串快照，**不建外键**到配置表 |

### 1.2 格式校验（PC 配置必做）

与现网下单实际写入值一致：**单点 `HH:mm`**（如 `08:00`），不是区间 `14:00-16:00`。

- 合法示例：`08:00`、`14:00`、`09:30`  
- 非法示例：`8:00`、`08:0`、`14:00-16:00`、`下午两点`、空串  

前后端都应校验；不通过时提示明确文案，例如：

> 时段格式须为 HH:mm，例如 08:00

（具体文案实现时可微调，含义不变。）

> 说明：创建订单 DTO 注释里曾出现区间 example，以**页面真实写入的 `HH:mm`** 为准做配置校验。

### 1.3 下单侧改动边界（尽量小）

| 改 | 不改 |
|----|------|
| 去掉本地时段常量，改为按 `bizType` 拉「已启用」列表 | `appointDate` / `appointTimeSlot` 字段名与含义 |
| 列表按配置的 `sortOrder` 展示 | 创建订单 API 契约、写库路径 |
| PC 代下单时段按钮同源 | 订单详情 / 列表 / 通知里对已存时段的展示逻辑 |
| Seed 写入当前 8 个整点（两套先相同） | 订单状态机、派单、通知；过近置灰 |

**本阶段不要求**创建订单时强制「必须在启用列表内」（避免扩大业务流程改动）。若防直调接口，可作为后续可选增强。

本阶段也不按「当前时刻」过滤按钮：今天已过的 `08:00` 仍展示、仍可点（与现网一致）。过滤是下一主题。

### 1.4 空配置与失败

- Seed 保证两套默认有启用时段，避免上线即空。默认仍用现网 8 个整点。  
- 接口失败：提示加载失败；是否回退本地默认 8 点实现时再定（倾向：至少 toast，避免静默空列表）。  
- 运营把某业务全部停用：下单页无按钮可选——配置页可提示「建议至少保留一个启用时段」（产品提示即可，非硬拦也可）。

## 2. 为什么单独一页（而不是塞进服务配置）

- 时段是**运营参数**，与 `ServiceCatalog`（保洁类型 / 大件小件）不是同一实体。  
- 保洁、废品要**两套独立列表**，需要清晰 Tab / 权限，和「关键词配置」同级更合适。  
- 订单页只消费「启用列表」，不负责维护。  
- **缓冲分钟**也是预约运营参数，下一主题加在本页顶部，不再另开菜单。

建议菜单：

| 用途 | 取值（建议） |
|------|----------------|
| 中文菜单 | 预约时段 |
| `menuKey` | `config.appoint-time-slots` |
| 路由 | `/config/appoint-time-slots` |
| 表 / 模块名 | `AppointTimeSlotConfig` / `appoint-time-slot` |

## 3. 分阶段要做什么（概念步骤，无代码）

本文仅 P1～P3：

```
P1  数据模型 + 种子（两套默认 8 点）+ 后端 CRUD / 公开查询
        ↓
P2  PC 配置管理页（双 Tab、格式校验、启停排序）—— 只要时段列表
        ↓
P3  替换 4 处硬编码数据源（居民保洁 / 居民回收 / PC 保洁代下单 / PC 回收代下单）
```

P1～P3 做完即可上线「可配格子」。置灰与缓冲见 [`appoint-time-lead-validation.md`](./appoint-time-lead-validation.md)，**不要**在本文加 P4。

### P1 后端能力（概念）

- 配置表含：`bizType`、时段文案、`sortOrder`、`isEnabled`。  
- 公开接口：按 `bizType` 返回已启用、按排序排列的列表（供小程序 / 代下单）。  
- 管理接口：分页全量 + 增删改 + 启停；写入时做 `HH:mm` 校验与同业务唯一校验。  
- 种子：CLEANING / RECYCLING 各写入现网 8 个点。  
- **不要**在本步加缓冲分钟字段（下一主题）。

### P2 PC 配置页（概念）

- 配置管理下新菜单 + 权限。  
- Tab 切换业务；表格展示文案 / 排序 / 状态 / 操作。  
- 新增 / 编辑弹窗：格式校验失败即报错，不提交。  
- 交互对标关键词配置页即可。  
- 页顶部先空着（或只有标题），给下一主题放两个缓冲数字。

### P3 消费方替换（概念）

四处硬编码改为请求对应 `bizType` 的启用列表：

1. 居民端保洁预约 Step2  
2. 居民端废品预约 Step2  
3. PC 新建保洁单时段按钮  
4. PC 新建废品单时段按钮  

进入选时段 UI 时加载；保存仍写原字段。仍全部可点，不过滤过近。
